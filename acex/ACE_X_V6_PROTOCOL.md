# ACE-X V6 Scientific Protocol

## Constraint

V6 is deliberately model-free:
- no LLM is required;
- no neural network is required;
- no learned world model is required;
- no cloud service is required;
- the cognitive kernel uses deterministic symbolic search, verification, memory, and executable transformations.

## Scientific target

V6 attacks the main remaining abstraction bottleneck:

**prospective, semantic library learning**.

The system must discover reusable abstractions even when independently solved tasks admit
different but behaviorally equivalent programs, and it must prefer abstractions that reduce
the acquisition cost of *future* tasks rather than merely compressing the historical corpus.

## Frozen capabilities

V6-A  Bounded semantic equivalence quotient over verified program behavior.

V6-B  Equivalence-aware abstraction induction: reusable concepts may be extracted from
       semantically equivalent but syntactically different solutions.

V6-C  Prospective compression: an abstraction is admitted only when evaluator-owned future
       tasks—not used to construct the abstraction—show lower verified acquisition cost.

V6-D  Executable mechanism change: a promoted mechanism must alter the actual search procedure
       (for example library-first or semantic-quotient search), not merely its accounting.

V6-E  Independent future-task generation: future tasks are generated from primitive expressions
       without consuming the candidate's learned concepts.

V6-F  Recursive library composition: later abstractions may call earlier verified abstractions.

V6-G  Typed transfer across Int and Bool task families.

V6-H  Proof-carrying promotion and rollback.

V6-I  Persistence via deterministic library digest.

V6-J  Failure-driven curriculum: failed successor tasks become new search targets.

## Terminal acceptance

Three evaluator-owned seed blocks must pass.

For every promoted abstraction:
- all visible tasks remain independently verified;
- every prospective future task remains independently verified;
- future acquisition cost must decrease;
- no hidden capability may regress;
- the mechanism must use its changed search procedure;
- rollback restores the exact parent digest and mechanism state.

No hidden task may be generated by calling the candidate's newly learned library.

## Kill rule

Any scientific failure after mechanical defects are excluded kills V6.
Thresholds, hidden tasks, and acceptance rules cannot be weakened after observing results.

## Claim boundary

A V6 PASS would establish semantic/prospective symbolic capability compounding under this
frozen environment. It would not establish AGI or ASI.

The next gate must broaden the task ontology beyond the current typed expression DSL and require
open-ended object, sequence, graph and interactive environments while preserving the same
model-free constraints.
