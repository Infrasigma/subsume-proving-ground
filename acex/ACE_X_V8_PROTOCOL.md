# ACE-X V8 Unified Cognitive Entity Protocol

## Engineering constraint

The entity must run without:
- LLMs,
- neural networks,
- learned world models,
- remote inference,
- cloud services.

Its core cognition is symbolic and executable.

## Objective

V8 is the first integrated entity gate. It must combine:
- semantic/prospective abstraction,
- persistent verified knowledge,
- surprise/failure memory,
- causal inquiry,
- interactive exploration,
- verified planning,
- macro induction,
- mechanism selection,
- proof-carrying promotion and rollback.

## Frozen capabilities

V8-A  Persistent capability registry with evidence lineage.

V8-B  Static semantic abstraction can be reused by the interactive runtime.

V8-C  Interactive experience can generate reusable procedural knowledge.

V8-D  Failure/surprise memory changes the next cognitive decision.

V8-E  Causal inquiry can select discriminating interventions and revise beliefs.

V8-F  The entity can move between observe -> remember -> inquire -> act -> verify ->
       consolidate without external model orchestration.

V8-G  Mechanism promotion changes executable search behavior and is independently
       verified before activation.

V8-H  Verified knowledge and procedures survive raw episode deletion.

V8-I  Rollback restores the exact previous cognitive state.

V8-J  Resource-normalized future-task improvement is demonstrated on held-out tasks.

## Terminal

Three protected seed blocks must exercise both static and interactive routes.

PASS requires every V8 capability above on every block.

A failure after mechanical defects are excluded kills V8.

## Claim boundary

V8 PASS is evidence that the integrated symbolic cognitive entity satisfies this frozen
experimental capability set. It is not a claim of human-level AGI or physical omnipotence.

A later ASI gate must broaden the environment ontology, tool invention, mathematical/scientific
reasoning, and open-ended mechanism invention while preserving the no-model/no-cloud constraint.
