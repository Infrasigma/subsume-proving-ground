# ASI Forge Protocol

This branch is an experimental ASI research forge, not an ASI claim.

## Frozen constraints

- TRUE ASI is the only target.
- No paid compute.
- Gemini is optional proposer only.
- Core intelligence must be generated by the tested software substrate.
- Evaluators and hidden cases are outside candidate control.
- Human task-specific intervention is forbidden during experiments.
- A benchmark score is never sufficient for a gate.
- INSUFFICIENT is never promoted to PASS.
- Auto-merge is disabled.

## Gate rule

F0-F15 are sequential evidence gates.

A gate can be PASS only if its independent experiment executes and satisfies its explicit acceptance condition. A failed or unimplemented gate blocks the ASI verdict.

F15 may report ASI only when every required preceding gate is satisfied and the final broad unseen-domain battery passes.

## Resource accounting

Every serious improvement must report:
- search/evaluation work,
- verification work,
- memory/artifact growth,
- successor semantic complexity,
- transfer/generalization outcome.

For recursive improvement, the important quantity is:

R_n = C(T_{n+1} | K_n) / C(T_{n+1} | K_0)

The target is repeated R_n < 1 on genuinely new task families, not simply a higher benchmark score.

## Scientific stop rule

If repeated adversarial experiments fail to produce:
1. increasing future-discovery power,
2. cross-domain transfer,
3. decreasing normalized discovery cost,
4. autonomous representation/mechanism invention,
5. broad hidden-domain competence,

the ASI route is killed rather than renamed AGI.
