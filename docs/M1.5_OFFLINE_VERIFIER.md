# AACR M1.5 — Offline Verifier

This branch implements the first executable form of AACR independent verification.

## Scope

- Parse a signed AACR envelope.
- Decode semantic JSON with exact integers.
- Apply AACR v0.1's fail-closed canonicalization profile.
- Compute SHA-256 over the canonical payload.
- Reconstruct the domain-separated signing message.
- Verify an Ed25519 signature offline.
- Expose an `aac verify` CLI surface.

The current canonicalizer is intentionally a restricted v0.1 profile and is **not** declared full RFC 8785/JCS conformance. Production conformance must use a vetted full RFC 8785 implementation before AACR labels an artifact conformant.

## Usage

```text
aac verify --public-key <64-hex-public-key> receipt.json
aac verify --public-key <64-hex-public-key> --evidence ./evidence --contract ./contract.json receipt.json
```

M1.5 accepts the future L2 flags but deliberately does not claim semantic evidence re-evaluation yet; that belongs to the next verifier increment with CEL.

## Next gate

Before the event ledger is added, this verifier must have cross-language test vectors and deterministic failure cases for malformed envelopes, altered payloads, altered signer IDs, wrong domains, invalid signatures, and rejected numeric forms.
